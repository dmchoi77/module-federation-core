# treeShakingSharedPlugins

독립 공유 fallback을 빌드할 때 사용할 플러그인 모듈 path 목록입니다. secondary tree-shaking 빌드 중 각 항목은 `require(p)`로 로드되고 instance화되어 compilation에 참여합니다.

- 타입: `string[]`
- 필수: 아니요
- 기본값: `undefined`

`shared.treeShaking.mode`가 `'server-calc'`로 설정되어 있으면 배포 서비스가 tree shaking이 필요한 shared dependencies를 다시 빌드합니다. 이 과정에서는 shared dependencies만 빌드되며 원래 프로젝트의 빌드 설정은 로드되지 않습니다.

원래 프로젝트가 `externals` 같은 특수 빌드 설정에 의존한다면, 그 설정을 NPM 플러그인으로 감싸 publish한 뒤 패키지 이름을 `treeShakingSharedPlugins`에 나열할 수 있습니다. secondary tree-shaking pass는 이 플러그인을 자동으로 `require`하고 instance화해 shared modules 빌드가 원래 설정을 상속받도록 합니다.

예를 들어 `externals`를 설정하는 `my-build-plugin` 플러그인을 제공한다고 가정해 보겠습니다.

```ts title='my-build-plugin'
class MyBuildPlugin {
  apply(compiler){
    compiler.options.externals = {
      'react': 'React',
    }
  }
}
export default MyBuildPlugin;
```

이 플러그인을 npm에 publish한 뒤에는 `treeShakingSharedPlugins`에 패키지 이름을 나열하면 됩니다.

```ts title='module-federation.config.ts'

export default {
  // ...
  treeShakingSharedPlugins: ['my-build-plugin@0.0.2'],
}
```

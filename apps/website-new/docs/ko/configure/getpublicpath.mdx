# getPublicPath

- 타입: `string`
- 필수: 아니요
- 기본값: `undefined`
- 적용 조건: `exposes`가 설정된 경우에만 적용됩니다.

동적 `publicPath`를 설정할 때 사용합니다. 값은 문자열로 직렬화한 함수이거나 문자열로 직렬화한 return 표현식이어야 합니다. 다른 consumer가 이 provider를 로드하면 `getPublicPath`의 문자열이 `new Function`으로 실행되고, 그 반환값이 모듈 정적 asset의 `publicPath` prefix로 사용됩니다. 예를 들어 배포된 프로젝트에서 동적 `cdn_prefix`를 받아야 한다면 다음처럼 설정할 수 있습니다.

- 함수 형식: ``function(){ return window.cdn_prefix }``
- 반환문 형식: ``return "https:" + window.navigator.cdn_host + "/리소스/app/"``

아래 예시에서는 `getPublicPath`를 설정합니다. 다른 consumer가 이 provider를 로드하면 `getPublicPath` 문자열이 `new Function`으로 실행되고, 그 결과가 모듈 정적 asset의 `publicPath` prefix로 사용됩니다.

:::tip 참고
`getPublicPath`는 문자열로 직렬화한 함수 또는 return 표현식이어야 합니다.
:::

:::tip 참고
Module Federation Webpack 플러그인에서 동적 publicPath를 설정하려면 `getPublicPath` 함수 본문 안에서 `__webpack_public_path__ = window.cdn_prefix`를 설정하세요.
:::

```ts title="rspack.config.ts"
module.exports = {
  plugins: [
    new ModuleFederationPlugin({
      name: 'provider',
      exposes: {
        './Button': './src/components/Button.tsx',
      },
      // ...
      getPublicPath: `function() {return "https:" + window.navigator.cdn_host + "/resource/app/"}`,
    }),
  ],
};
```

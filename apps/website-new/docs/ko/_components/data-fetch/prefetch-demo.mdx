### 시나리오 1: 데이터만 prefetch

사용자가 shop 페이지로 이동하는 링크에 hover하면, 해당 페이지에 필요한 데이터를 미리 가져올 수 있습니다.

```ts
import { getInstance } from '@module-federation/enhanced/runtime';

const instance = getInstance();

const handleMouseEnter = () => {
  instance.prefetch({
    id: 'shop/Button',
    dataFetchParams: { productId: '12345' },
  });
};
```

### 시나리오 2: 데이터 prefetch와 컴포넌트 리소스 preload

더 최적화하려면 데이터를 prefetch하는 동시에 컴포넌트의 JS와 CSS 파일도 함께 다운로드할 수 있습니다.

```ts
import { getInstance } from '@module-federation/enhanced/runtime';

const instance = getInstance();

const handleMouseEnter = () => {
  instance.prefetch({
    id: 'shop/Button',
    dataFetchParams: { productId: '12345' },
    preloadComponentResource: true,
  });
};
```

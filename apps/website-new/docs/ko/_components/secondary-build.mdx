## Secondary tree-shaken shared artifact 만들기

:::warning 참고
목표가 “단일 애플리케이션에서 shared dependency를 tree-shake하는 것”이라면 보통 [usedExports](/configure/shared.html#usedexports)만으로 충분합니다.

이 섹션은 런타임에서 온디맨드로 로드할 수 있고, 배포 시스템에서 배포하거나 재사용할 수 있는 독립 보조 산출물을 만드는 방법을 다룹니다.
:::

이 과정에서는 shared dependencies만 빌드합니다. remote 설정은 적용되지 않습니다. 빌드 중에는 원래 프로젝트 엔트리가 자동으로 무시되고, shared modules만 번들에 포함됩니다.

### Modern.js가 아닌 프로젝트

빌드 설정에서 `TreeShakingSharedPlugin`을 사용하고 `secondary: true`를 설정하세요. 기존 `mfConfig`는 그대로 재사용할 수 있습니다.

import { Tab, Tabs } from '@theme';

<Tabs>
  <Tab label="@module-federation/enhanced">
  ```ts
  import { TreeShakingSharedPlugin } from '@module-federation/enhanced';
  // import { TreeShakingSharedPlugin } from '@module-federation/enhanced/rspack';
  // ...
  plugins: [
    new TreeShakingSharedPlugin({
      secondary: true,
      mfConfig,
    }),
  ];
  ```
  </Tab>
  <Tab label="@module-federation/rsbuild-plugin">
  ```ts
  import { TreeShakingSharedPlugin } from '@module-federation/rsbuild-plugin';
  // ...
  plugins: [
    new TreeShakingSharedPlugin({
      secondary: true,
      mfConfig,
    }),
  ];
  ```
  </Tab>
  <Tab label="Rspack 내장">
  ```ts
  import { sharing } from '@rspack/core';
  const { TreeShakingSharedPlugin } = sharing;
  // ...
  plugins: [
    new TreeShakingSharedPlugin({
      secondary: true,
      mfConfig,
    }),
  ];
  ```
</Tab>
</Tabs>

### Modern.js 프로젝트

`@module-federation/modern-js-v3`를 사용한다면 플러그인 옵션에 `secondarySharedTreeShaking: true`를 설정해 보조 산출물을 생성합니다.

```ts title="modern.config.ts"
import mfPlugin from '@module-federation/modern-js-v3';
// ...
plugins: [
  mfPlugin({
    secondarySharedTreeShaking: true,
  }),
];
```

# Module Federation 블로그

Module Federation의 최신 글과 릴리스 공지를 확인할 수 있습니다.

## [Module Federation 2.0 안정 버전 릴리스](/blog/v2-stable-version.html)

> February 10, 2026

Module Federation 2.0이 공식 안정 버전이 되었습니다. shared-dependency tree shaking과 Modern.js v3 플러그인으로 통합이 더 쉬워졌습니다.

## [Node.js에서 Module Federation 쉽게 사용하기](/blog/node.html)

> January 23, 2026

런타임만 사용하는 방식, Rspack/Webpack 통합, producer 쪽 빌드 설정까지 Node.js에서 Module Federation을 사용하는 방법을 살펴봅니다.

## [remote 모듈 렌더링 오류 처리하기](/blog/error-load-remote.html)

> September 9, 2025

remote 모듈 로드와 렌더링 실패를 처리하는 fallback strategies를 다룹니다. 네트워크 재시도, `errorLoadRemote` hook, React ErrorBoundary를 함께 살펴봅니다.

## [릴리스 공지](/blog/announcement.html)

> April 26, 2024

Module Federation 2.0의 공식 릴리스를 알리고, 런타임 분리, 타입 안정성, devtools, Manifest 프로토콜 같은 핵심 기능을 소개합니다.

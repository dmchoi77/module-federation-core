# AI 빠른 시작

:::tip 문서를 직접 읽고 싶다면
Module Federation의 개념, 설정, 통합 방법을 순서대로 보고 싶다면 [시작 가이드](/guide/start/index.html)부터 읽어 보세요.
:::

## 더 빠르게 시작하는 방법

이미 AI 코딩 도구를 쓰고 있다면 모든 문서를 먼저 읽을 필요는 없습니다.

더 빠른 방법은 간단합니다. **AI 에이전트가 최신 Module Federation 문서를 먼저 읽게 한 뒤, 질문 답변, 문제 분석, 설정 수정, 코드 작성을 맡기세요.**

많은 모델은 아직 Module Federation 2.0에 대한 지식이 부족하거나 오래된 정보를 바탕으로 답합니다. 이 페이지의 목적은 사용자가 먼저 공부하도록 만드는 것이 아니라, 에이전트가 정확한 원문 자료를 먼저 참고하도록 돕는 것입니다.

## 권장 설정

Claude Code, Cursor, Windsurf처럼 Skills를 지원하는 편집기나 AI 코딩 도구를 사용한다면 다음 skill을 설치하세요.

```bash
npx skills add module-federation/agent-skills --skill mf -y
```

그다음 답변하기 전에 문서를 먼저 읽도록 요청합니다.

```text
/mf docs What's the difference between singleton and requiredVersion in shared?
```

핵심은 다음과 같습니다.

- 사용자가 문서를 직접 뒤질 필요가 줄어듭니다.
- 에이전트가 답하기 전에 최신 문서를 확인합니다.
- 오래된 지식으로 추측할 가능성이 낮아집니다.

## 에이전트에 더 많은 일을 맡기고 싶다면

`mf` skill은 문서 기반 질의응답만 처리하지 않습니다. 다음 작업도 에이전트가 진행할 수 있습니다.

- 기존 프로젝트에 Module Federation 추가
- 설정 문제 점검
- 타입 관련 문제 분석
- shared dependencies 충돌 확인
- remote 모듈 정보 확인
- observability 리포트를 읽고 MF 로딩 실패 디버깅

👉 [Agent Skills 문서 보기](/ai/skill.html)

## MF 로딩 observability와 디버깅

AI 코딩 에이전트가 실제 런타임 정보를 바탕으로 Module Federation 로딩 문제를 디버깅하게 하려면 먼저 [Observability Plugin](/plugin/plugins/observability-plugin.html)을 활성화하세요.

로딩에 실패하면 브라우저 콘솔에 `traceId`가 출력됩니다. 개발 환경에서는 `read:` 명령도 함께 표시됩니다. 이 콘솔 힌트를 에이전트에게 그대로 전달하면 됩니다.

```text
/mf observability
Module Federation 콘솔 에러를 확인했습니다.

[Module Federation] Observability report generated
traceId: mf-...
read: window.__FEDERATION__.__OBSERVABILITY__["runtime_host"].getReport("mf-...")

리포트를 읽고 문제를 수정해 주세요.
```

Node 또는 SSR 환경에서는 에이전트에게 `.mf/observability/latest.json`을 읽게 하세요. 프로덕션에서는 플러그인의 `onReport` 콜백으로 리포트를 업로드한 뒤, 업로드된 리포트나 trace ID를 에이전트에게 전달하면 됩니다.

## 설치 없이 가볍게 써보기

먼저 가벼운 방식으로 시작하고 싶다면 아래 문장을 에이전트에게 직접 전달하세요.

```text
답변하기 전에 https://module-federation.io/llms.txt 를 읽고 최신 Module Federation 2.0 문서를 확인한 뒤 제 질문에 답해 주세요.
```

아직 skill을 설치하지 않았더라도, 모델이 추측으로 답하는 일을 줄이는 가장 쉬운 방법입니다.

## 에이전트에게 전달할 수 있는 문서

### llms.txt

[module-federation.io](https://module-federation.io)는 AI 시스템이 문서를 읽기 쉽게 사용할 수 있도록 [llms.txt](https://llmstxt.org) 표준을 지원합니다.

```text
https://module-federation.io/llms.txt
```

### Markdown 문서

문서 사이트의 모든 페이지는 Markdown 형식으로도 제공됩니다. 문서 URL 끝의 `.html`을 `.md`로 바꾸면 됩니다.

```text
# HTML 버전
https://module-federation.io/guide/basic/runtime.html

# Markdown 버전
https://module-federation.io/guide/basic/runtime.md
```

## 다음 단계

바로 이 흐름을 사용하려면 다음 순서로 진행하세요.

1. `mf`를 설치합니다.
2. 가장 궁금한 질문을 에이전트에게 묻습니다.
3. MF loading observability가 필요할 때 [Observability Plugin](/plugin/plugins/observability-plugin.html)을 활성화합니다.
4. 지원하는 하위 명령은 [Skills 문서](/ai/skill.html)에서 확인합니다.

# 명령줄 도구

{props.name || 'Module Federation'}은 <code>{props.cmd || 'mf'}</code>라는 가벼운 CLI를 제공합니다. 이 명령은 <code>{props.cmdTool || '@module-federation/enhanced'}</code> 패키지에 포함되어 있습니다.

:::note
[통합 가이드](/integrations/index.html)를 따라 설정을 마쳤다면 보통 <code>{props.cmdTool || '@module-federation/enhanced'}</code>가 이미 의존성에 포함되어 있어 바로 사용할 수 있습니다. 그렇지 않다면 아래 명령을 실행하기 전에 프로젝트에 직접 설치하세요.
:::

## 전체 명령 보기

import React from 'react';
import ViewAllCmdsMdx from '@docs/ko/_components/cli/view-all-cmds';

{/* rspress flattenMdxContent issue */}
{props.show || React.createElement(ViewAllCmdsMdx)}

## 공통 옵션

{props.name || 'Module Federation'} CLI는 모든 명령에서 사용할 수 있는 공통 옵션을 제공합니다.

| 옵션 | 설명 |
| --- | --- |
| `-c, --config <config>` | 설정 파일 경로를 지정합니다. 상대 경로와 절대 경로를 모두 사용할 수 있습니다. 기본값은 {props.configName ? props.configName : 'module-federation.config.ts' }입니다. |
| `-m, --mode <mode>` | 실행 환경을 지정합니다. `"dev"` 또는 `"prod"`를 선택할 수 있으며 기본값은 `"dev"`입니다. 값에 따라 `process.env.NODE_ENV`에 `"development"` 또는 `"production"`이 자동으로 주입됩니다. |
| `-h, --help` | 명령 도움말을 표시합니다. |

## {props.cmd || 'mf'} dts

<code>{props.cmd || 'mf'} dts</code>는 TypeScript 타입 선언 파일을 가져오거나 생성할 때 사용합니다.

import CommandInfo from '@docs/_snippets/cli/cmd-info';

{props.commandInfo || <CommandInfo />}

:::info 주의

<code>{props.cmd || 'mf'} dts</code> 명령은 <code>{props.configName || 'module-federation.config.ts'}</code> 설정을 기준으로 타입 선언 파일을 생성하거나 가져옵니다. 따라서 유효한 설정 파일이 필요하며, 설정 파일이 없거나 올바르지 않으면 명령이 정상적으로 실행되지 않습니다.

런타임 API만 사용하는 경우에는 임시 <code>{props.configName || 'module-federation.config.ts'}</code> 파일을 만들고 [dts.consumeTypes.remoteTypeUrls](/configure/dts.html#remotetypeurls)를 설정한 뒤 `mf dts` 명령을 실행하세요.

:::

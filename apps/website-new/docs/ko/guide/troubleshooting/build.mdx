## BUILD-001

<ErrorCodeTitle code='BUILD-001'/>

### 원인

Expose 모듈 리소스를 찾지 못했습니다.

가능한 원인은 두 가지입니다.

1. `exposes`에 설정한 exposeModules 파일 경로가 잘못되어 존재하지 않는 경로를 가리킵니다.
2. `Next.js`처럼 Webpack을 내장한 framework를 사용할 때, MF가 사용하는 Webpack 경로와 framework가 사용하는 Webpack 경로가 일치하지 않습니다.

### 해결 방법

1. exposes의 모듈 파일 경로가 올바른지 확인합니다. 대소문자도 함께 확인하세요.
2. `FEDERATION_WEBPACK_PATH`가 framework에서 사용하는 Webpack 경로와 일치하는지 확인하세요. 일치하지 않는다면 의존성이 올바르게 설치되어 있는지 확인하거나, `process.env.FEDERATION_WEBPACK_PATH`를 실제 Webpack 경로로 설정하세요.

## BUILD-002

<ErrorCodeTitle code='BUILD-002'/>

### 원인

Rspress producer를 빌드할 때는 프로젝트에 `publicPath`를 설정해야 합니다. 설정하지 않으면 다른 consumer가 정상적으로 로드할 수 없습니다.

### 해결 방법

다음 방법 중 하나로 `publicPath`를 설정합니다.

* `rspress.config.ts`에서 [builderConfig.output.assetPrefix](https://rsbuild.rs/config/output/asset-prefix)를 설정합니다.

```ts title="rspress.config.ts"
export default {
  builderConfig: {
    output: {
      assetPrefix: 'https://module-federation.io/',
    }
  }
}
```

* `rspress.config.js`에서 [builderConfig.tools.rspack](https://rsbuild.rs/config/tools/rspack)을 설정합니다.

```ts title="rspress.config.ts"
export default {
  builderConfig: {
    tools: {
      rspack: (config)=>{
        config.output.publicPath = 'https://module-federation.io/';
      },
    }
  }
}
```

## 자주 발생하는 문제(에러 코드 없음)

### CORS 경고

프로젝트에 `exposes`가 설정되어 있으면 producer로 간주됩니다. consumer가 producer 리소스를 정상적으로 로드할 수 있도록 `@module-federation/modern-js-v3`와 `@module-federation/rsbuild-plugin`은 `Access-Control-Allow-Origin`을 `*`로 설정하고 동시에 경고를 출력합니다.

#### 해결 방법

* [Modern.js]: [devServer.headers](https://modernjs.dev/configure/app/tools/dev-server.html#headers) 값을 `*` 대신 지정한 domain whitelist로 설정합니다.

* [Rsbuild]: [server.cors.origin](https://rsbuild.dev/config/server/cors#origin) 값을 `*` 대신 지정한 domain whitelist로 설정합니다.

### Multiple assets emit different content to the same filename mf-manifest.json

#### 원인

Rspack `1.6.0-beta.0`에서 manifest 구현이 Rust로 이식되었습니다. MF 관련 패키지를 함께 업그레이드하지 않고 Rspack만 업그레이드하면 이 오류가 발생합니다.

#### 해결 방법

`@module-federation` scope의 npm 패키지를 0.21.0 이상으로 업그레이드하세요.

`Module Federation`에서 모듈을 등록하고 불러오는 방법은 크게 두 가지입니다.

- 빌드 플러그인에서 선언합니다. 보통 `module-federation.config.ts` 파일에 설정합니다.
- `runtime` API로 직접 모듈을 등록하고 불러옵니다.

두 방식은 서로 배타적이지 않습니다. 같은 프로젝트 안에서도 상황에 맞게 함께 사용할 수 있습니다.

## 두 방식의 차이

| 런타임에서 모듈 등록 | 플러그인에서 모듈 등록 |
| --- | --- |
| 빌드 플러그인 없이 사용할 수 있으며, `webpack4` 같은 프로젝트에서도 pure runtime으로 모듈 등록과 로딩을 처리할 수 있습니다. | 빌드 플러그인은 webpack5 이상이 필요합니다. |
| 동적으로 모듈을 등록할 수 있습니다. | 동적 모듈 등록을 지원하지 않습니다. |
| `import` 문법으로 모듈을 불러올 수 없습니다. | `import` 문법으로 모듈을 불러올 수 있습니다. |
| `loadRemote`로 모듈을 불러올 수 있습니다. | `loadRemote`로 모듈을 불러올 수 있습니다. |
| `shared` 설정에 구체적인 버전과 인스턴스 정보를 직접 제공해야 합니다. | `shared`에는 재사용 규칙만 설정하면 됩니다. |
| shared dependencies는 외부에서 제공된 것만 사용할 수 있고, 외부 shared dependencies를 다시 제공하지는 않습니다. | 규칙에 따라 shared dependencies를 양방향으로 재사용합니다. |
| `runtime`의 `plugin` 메커니즘으로 로딩 과정을 제어할 수 있습니다. | 현재는 로딩 과정에 영향을 주는 `plugin` 제공을 지원하지 않습니다. |
| remote 타입 힌트를 지원하지 않습니다. | remote 타입 힌트를 지원합니다. |

## 설치

프로젝트 유형에 따라 런타임을 설치하고 import하는 entry가 다릅니다. 대부분의 프로젝트는 `@module-federation/enhanced`를 설치하고 `@module-federation/enhanced/runtime`에서 런타임 API를 import하면 됩니다.

Modern.js 프로젝트에서 이미 Module Federation 플러그인을 사용하고 있다면, 플러그인의 `/runtime` entry에서 런타임 API를 import하세요. 그래야 프레임워크 플러그인과 직접 호출한 런타임 API가 같은 런타임 인스턴스를 사용합니다.

## 모듈 등록

<Tabs>
  <Tab label="빌드 플러그인 사용">
  ```tsx
  // 빌드 플러그인을 사용하면 `registerRemotes`를 바로 사용할 수 있습니다.
  import { registerRemotes } from '@module-federation/enhanced/runtime';

  registerRemotes([
    {
        name: 'remote1',
        alias: 'remote-1',
        entry: 'http://localhost:3001/mf-manifest.json',
    }
  ]);
  ```
  </Tab>
  <Tab label="Pure Runtime 사용">
  ```ts
  // 빌드 플러그인을 사용하지 않는 경우 새 인스턴스를 만들고 remote를 등록합니다.
  import { createInstance } from '@module-federation/enhanced/runtime';

  const mf = createInstance({
    name: 'mf_host',
    remotes: [
      {
        name: 'remote1',
        alias: 'remote-1',
        entry: 'http://localhost:3001/mf-manifest.json',
      }
    ]
  });

  mf.registerRemotes([
    {
        name: 'remote1',
        alias: 'remote-1',
        entry: 'http://localhost:3001/mf-manifest.json',
    }
  ]);
  ```
  </Tab>
</Tabs>

## 모듈 로딩

<Tabs>
  <Tab label="빌드 플러그인 사용">
  ```tsx
  // 빌드 플러그인을 사용하면 `loadRemote`를 바로 사용할 수 있습니다.
  import { loadRemote } from '@module-federation/enhanced/runtime';
  import React from 'react';

  export default () => {
    const MyButton = React.lazy(() =>
      loadRemote('remote1').then(({ MyButton }) => {
        return {
          default: MyButton
        };
      }),
    );

    return (
      <React.Suspense fallback="Loading Button">
        <MyButton />
      </React.Suspense>
    );
  }
  ```
  </Tab>

  // 빌드 플러그인을 사용하지 않는 경우 새 인스턴스를 만들고 remote를 불러옵니다.
  import { createInstance } from '@module-federation/enhanced/runtime';

  const mf = createInstance({
    name: 'mf_host',
    remotes: [
      {
        name: 'remote1',

        entry: 'http://localhost:3001/mf-manifest.json',

### 유틸리티 함수 로딩

<Tabs>
    <Tab label="빌드 플러그인 사용">
    ```tsx
    // 빌드 플러그인을 사용하면 `loadRemote`를 바로 사용할 수 있습니다.
    import React from 'react';
    import { loadRemote } from '@module-federation/enhanced/runtime';

    // remote1이 expose한 util을 불러옵니다.
    loadRemote<{add: (...args: Array<number>)=> number }>("remote1/util").then((md)=>{
        md.add(1,2);
    });
    ```
    </Tab>

    import { createInstance, loadRemote } from '@module-federation/enhanced/runtime';
    import React from 'react';

    const mf = createInstance({
      name: 'mf_host',
      remotes: [

          name: 'remote1',

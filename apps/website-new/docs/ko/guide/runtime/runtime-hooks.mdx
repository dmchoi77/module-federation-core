# 런타임 훅

Module Federation 런타임은 remote 모듈 로드, 컨테이너 초기화, shared dependencies 등록과 해석 같은 주요 단계에서 훅을 제공합니다. 이 훅은 진단, 추적, 오류 시 fallback, shared dependencies 재작성, 리소스 로딩 커스터마이징에 유용합니다.

## 훅 반환값

`SyncHook`과 `AsyncHook`에서 `undefined`를 반환하면 해당 플러그인은 이벤트를 관찰만 한다는 뜻입니다. 이전 플러그인이 반환한 값을 지우지 않습니다. 이후 플러그인은 `undefined`가 아닌 값을 반환해 여전히 그 값을 대체할 수 있습니다.

`SyncWaterfallHook`과 `AsyncWaterfallHook`에서 페이로드를 바꿔야 한다면 업데이트된 전체 args 객체를 반환하세요. `undefined`를 반환하면 현재 args를 유지한 채 다음 플러그인으로 전달합니다.

## errorLoadRemote

`AsyncHook`

remote 로딩이 실패했을 때 호출되며, 사용자 정의 오류 처리를 적용할 수 있습니다. 사용자 정의 fallback logic을 반환할 수도 있습니다.

```ts
async function errorLoadRemote(
  args: ErrorLoadRemoteOptions,
): Promise<void | unknown>;

type ErrorLoadRemoteOptions = {
  id: string;
  error: unknown;
  options?: any;
  from: 'build' | 'runtime';
  lifecycle: 'beforeRequest' | 'beforeLoadShare' | 'afterResolve' | 'onLoad';
  remote?: RemoteInfo;
  expose?: string;
  origin: ModuleFederation;
};
```

`lifecycle` 매개변수는 오류가 발생한 단계를 나타냅니다.

- `beforeRequest`: 초기 요청 처리 중 오류
- `afterResolve`: manifest 로딩 중 오류(네트워크 실패에서 가장 흔함)
- `onLoad`: 모듈 로딩과 실행 중 오류
- `beforeLoadShare`: shared dependencies 초기화 중 remoteEntry를 로드하다 발생한 오류

이 훅이 fallback module을 반환하면 런타임은 그 값을 사용해 계속 진행합니다. 진단 또는 로깅 플러그인이 `undefined`를 반환하더라도 다른 플러그인이 반환한 fallback은 지워지지 않습니다.

```ts
import { createInstance, loadRemote } from '@module-federation/enhanced/runtime';

import type { ModuleFederationRuntimePlugin } from '@module-federation/enhanced/runtime';

const fallbackPlugin: () => ModuleFederationRuntimePlugin =
  function () {
    return {
      name: 'fallback-plugin',
      errorLoadRemote(args) {
        const { lifecycle, id, error } = args;

        if (error) {
          console.warn(\`\${lifecycle} 단계에서 remote \${id} 로딩 실패:\`, error?.message || error);
        }

        switch (lifecycle) {
          case 'afterResolve':
            return {
              id: id || 'fallback',
              name: id || 'fallback',
              metaData: { /* 대체 manifest */ },
              shared: [],
              remotes: [],
              exposes: []
            };

          case 'beforeRequest':
            console.warn(\`\${id} 요청 처리 실패\`);
            return void 0;

          case 'onLoad':
            return () => ({
              __esModule: true,
              default: () => 'fallback component'
            });

          case 'beforeLoadShare':
            console.warn(\`\${id} shared dependencies 로딩 실패\`);
            return () => ({
              __esModule: true,
              default: {}
            });

          default:
            console.warn(\`\${id}에서 알 수 없는 lifecycle \${lifecycle}\`);
            return void 0;
        }
      },
    };
  };

const mf = createInstance({
    name: 'mf_host',
    remotes: [
        {
            name: "remote",
            alias: "app1",
            entry: "http://localhost:2001/mf-manifest.json"
        }
    ],
    plugins: [fallbackPlugin()]
});

mf.loadRemote('app1/un-existed-module').then(mod=>{
  expect(mod).toEqual('fallback');
});
```

## resolveShare

`SyncWaterfallHook`

최종 shared module selection result를 덮어쓸 수 있습니다.

`resolveShare`는 런타임이 후보 scope와 버전을 이미 선택한 뒤 실행됩니다. 이 시점에서 `args`의 `scope`나 `version` 같은 필드를 바꾸는 것만으로는 최종 결과가 바뀌지 않습니다. 다른 shared modules로 전환하려면 `args.resolver`를 교체하고 사용할 공유 레코드를 반환해야 합니다.

```ts
function resolveShare(args: ResolveShareOptions): ResolveShareOptions;

type ResolveShareOptions = {
  shareScopeMap: ShareScopeMap;
  scope: string;
  pkgName: string;
  version: string;
  shareInfo: Shared;
  GlobalFederation: Federation;
  resolver: () =>
    | {
        shared: Shared;
        useTreesShaking: boolean;
      }
    | undefined;
};
```

```ts
import {
  createInstance,
  loadRemote,
} from '@module-federation/enhanced/runtime';

import type { ModuleFederationRuntimePlugin } from '@module-federation/enhanced/runtime';

const customSharedPlugin: () => ModuleFederationRuntimePlugin = function () {
  return {
    name: 'custom-shared-plugin',
    resolveShare(args) {
      const { pkgName, shareScopeMap } = args;

      if (pkgName !== 'react') {
        return args;
      }

      const fallbackShared = shareScopeMap.default?.react?.['17.0.0'];
      if (!fallbackShared) {
        return args;
      }

      args.resolver = function () {
        return {
          shared: fallbackShared,
          useTreesShaking: false,
        };
      };
      return args;
    },
  };
};

const mf = createInstance({
  name: 'mf_host',
  shared: {
    react: {
      version: '17.0.0',
      scope: 'default',
      lib: () => React,
      shareConfig: {
        singleton: true,
        requiredVersion: '^17.0.0',
      },
    },
  },
  plugins: [customSharedPlugin()],
});

mf.loadShare('react').then((reactFactory) => {
  expect(reactFactory()).toEqual(React);
});
```

## createScript

`SyncHook`

리소스를 로드할 때 사용할 script 요소를 수정하는 데 사용합니다.

```ts
function createScript(args: CreateScriptOptions): CreateScriptHookReturn;

type CreateScriptOptions = {
  url: string;
  attrs?: Record<string, any>;
  remoteInfo?: RemoteInfo;
  resourceContext?: ResourceLoadContext;
};

type CreateScriptHookReturn =
  | HTMLScriptElement
  | { script?: HTMLScriptElement; timeout?: number }
  | void;

type ResourceLoadContext = {
  initiator: 'loadRemote' | 'preloadRemote';
  id: string;
  resourceType: 'manifest' | 'remoteEntry' | 'js' | 'css';
  url?: string;
};
```

`timeout`은 밀리초 단위이며 script 로딩 타임아웃을 제어합니다. 기본값은 `20000`입니다.
`resourceContext`는 이 리소스 로드가 `loadRemote`에서 시작됐는지 `preloadRemote`에서 시작됐는지, 그리고 리소스 타입과 ID가 무엇인지 알려 줍니다.
`timeout`과 `resourceContext`를 함께 사용하면 remoteEntry 로딩과 프리로드 로딩에 서로 다른 타임아웃을 설정할 수 있습니다.

```ts
import type { ModuleFederationRuntimePlugin } from '@module-federation/enhanced/runtime';

const changeScriptAttributePlugin: () => ModuleFederationRuntimePlugin =
  function () {
    return {
      name: 'change-script-attribute',
      createScript({ url }) {
        if (url === 'http://localhost:3001/remoteEntry.js') {
          let script = document.createElement('script');
          script.src = url;
          script.setAttribute('loader-hooks', 'isTrue');
          script.setAttribute('crossorigin', 'anonymous');
          return {
            script,
            timeout: 30000,
          };
        }
      },
    };
  };
```

## fetch

`AsyncHook`

`fetch` 함수는 manifest JSON을 가져오는 요청을 커스터마이징할 수 있게 합니다. 성공한 `Response`는 유효한 JSON을 반환해야 합니다.

```typescript
function fetch(
  manifestUrl: string,
  requestInit: RequestInit,
  remoteInfo?: RemoteInfo,
  resourceContext?: ResourceLoadContext,
): Promise<Response> | void | false;
```

`resourceContext`를 보면 이 manifest 요청이 `loadRemote`에서 왔는지 `preloadRemote`에서 왔는지 알 수 있습니다.

- manifest JSON을 가져올 때 인증 정보(credentials)를 포함하는 예시:

```ts
import type { FederationRuntimePlugin } from '@module-federation/enhanced/runtime';

// fetch-manifest-with-credentials-plugin.ts
export default function (): FederationRuntimePlugin {
  return {
    name: 'fetch-manifest-with-credentials-plugin',
    fetch(manifestUrl, requestInit) {
      return fetch(manifestUrl, {
        ...requestInit,
        credentials: 'include',
      });
    },
  };
}
```


`resourceContext`는 `createScript`와 같은 형태입니다. 프리로드된 JS/CSS, 실제 remoteEntry 로딩, 관련 리소스 ID를 구분할 수 있습니다.
`timeout`은 밀리초 단위이며 link 로딩 타임아웃을 제어합니다. 기본값은 `20000`입니다.

예시: 낮은 우선순위의 프리로드 리소스에는 짧은 타임아웃을 사용하고, 일반 remote 로딩에는 더 여유 있는 타임아웃을 유지합니다.

```ts
import type { ModuleFederationRuntimePlugin } from '@module-federation/enhanced/runtime';

const resourceTimeoutPlugin = (): ModuleFederationRuntimePlugin => ({
  name: 'resource-timeout-plugin',
  createScript({ resourceContext }) {
    if (
      resourceContext?.initiator === 'loadRemote' &&
      resourceContext.resourceType === 'remoteEntry'
    ) {
      return {
        timeout: 30000,
      };
    }
  },
  createLink({ resourceContext }) {
    if (resourceContext?.initiator === 'preloadRemote') {
      return {
        timeout: 5000,
      };
    }
  },
});
```

## loadEntry

`asyncHook`

`loadEntry` 함수는 remote를 완전히 커스터마이징할 수 있게 해, 새로운 remote 타입을 확장하거나 만들 수 있습니다. 아래 두 예시는 JSON 데이터 로딩과 모듈 위임을 보여 줍니다.

```typescript
function loadEntry(args: LoadEntryOptions): RemoteEntryExports | void;

type LoadEntryOptions = {
  createScriptHook: SyncHook;
  remoteEntryExports?: RemoteEntryExports;
  remoteInfo: RemoteInfo;
};
interface RemoteInfo {
  name: string;
  version?: string;
  buildVersion?: string;
  entry: string;
  type: RemoteEntryType;
  entryGlobalName: string;
  shareScope: string;
}
export type RemoteEntryExports = {
  get: (id: string) => () => Promise<Module>;
  init: (
    shareScope: ShareScopeMap[string],
    initScope?: InitScope,
    remoteEntryInitOPtions?: RemoteEntryInitOptions,
  ) => void | Promise<void>;
};
```

- JSON 데이터 로딩 예제

```ts
import { init } from '@module-federation/enhanced/runtime';

import type { FederationRuntimePlugin } from '@module-federation/enhanced/runtime';

// load-json-data-plugin.ts
const changeScriptAttributePlugin: () => FederationRuntimePlugin = function () {
  return {
    name: 'load-json-data-plugin',
    loadEntry({ remoteInfo }) {
      if (remoteInfo.jsonA === 'jsonA') {
        return {
          init(shareScope, initScope, remoteEntryInitOPtions) {},
          async get(path) {
            const json = await fetch(remoteInfo.entry + '.json').then((res) =>
              res.json(),
            );
            return () => ({
              path,
              json,
            });
          },
        };
      }
    },
  };
};
```

```ts
// module-federation-config
{
  remotes: {
    jsonA: "jsonA@https://cdn.jsdelivr.net/npm/@module-federation/runtime/package";
  }
}
```

```ts
// src/bootstrap.js
import jsonA from 'jsonA';
jsonA; // {...json data}
```

- 모듈 위임 예제

```ts
import { init } from '@module-federation/enhanced/runtime';

import type { FederationRuntimePlugin } from '@module-federation/enhanced/runtime';

// delegate-modules-plugin.ts
const changeScriptAttributePlugin: () => FederationRuntimePlugin = function () {
  return {
    name: 'delegate-modules-plugin',
    loadEntry({ remoteInfo }) {
      if (remoteInfo.name === 'delegateModulesA') {
        return {
          init(shareScope, initScope, remoteEntryInitOPtions) {},
          async get(path) {
            path = path.replace('./', '');
            const { [path]: factory } = await import('./delegateModulesA.js');
            const result = await factory();
            return () => result;
          },
        };
      }
    },
  };
};
```

```ts
// ./src/delegateModulesA.js
export async function test1() {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve('test1 value');
    }, 3000);
  });
}
export async function test2() {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve('test2 value');
    }, 3000);
  });
}
```

```ts
// module-federation-config
{
  remotes: {
    delegateModulesA: 'delegateModulesA@https://delegateModulesA.js';
  }
}
```

```ts

import test1 from 'delegateModulesA/test1';
import test2 from 'delegateModulesA/test2';

test2; // "test2 value"
```

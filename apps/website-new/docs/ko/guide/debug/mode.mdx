# 디버그 모드 활성화

문제 해결을 돕기 위해 {props.name || 'Module Federation'}은 디버그 모드를 제공합니다. 빌드를 실행할 때 `FEDERATION_DEBUG=true` 환경 변수를 추가하거나, 브라우저에서 `localStorage.setItem('FEDERATION_DEBUG','true')`를 실행하면 디버그 모드를 활성화할 수 있습니다.

빌드 시 환경 변수 추가:

```bash
# 개발 모드 디버깅
FEDERATION_DEBUG=true pnpm dev

# 프로덕션 모드 디버깅
FEDERATION_DEBUG=true pnpm build
```

런타임에서 환경 변수 추가:

```
localStorage.setItem('FEDERATION_DEBUG','true')
```

## 로그 정보

디버그 모드를 활성화하면 콘솔에서 다음 정보를 확인할 수 있습니다.

디버그 모드에서는 터미널에 [ <code>{props.name || 'Module Federation'}</code> ]로 시작하는 로그가 출력됩니다.

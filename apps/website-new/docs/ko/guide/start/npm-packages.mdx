# NPM 패키지

이 문서는 Module Federation 팀이 관리하는 npm 패키지를 소개합니다.

## @module-federation/enhanced

![](https://img.shields.io/npm/v/@module-federation/enhanced?style=flat-square&colorA=564341&colorB=EDED91)

Module Federation의 핵심 패키지입니다. Webpack 빌드 플러그인, Rspack 빌드 플러그인, 런타임 진입점 의존성으로 사용됩니다.

- [npm](https://npmjs.com/package/@module-federation/enhanced)
- [소스 코드](https://github.com/module-federation/core/tree/main/packages/enhanced)
- [런타임 문서](/guide/runtime/index.html)
- [Rspack 빌드 플러그인](/integrations/bundler/rspack.html)
- [Webpack 빌드 플러그인](/integrations/bundler/webpack.html)

## @module-federation/runtime

![](https://img.shields.io/npm/v/@module-federation/runtime?style=flat-square&colorA=564341&colorB=EDED91)

Module Federation 런타임 패키지입니다. 일반적으로 `@module-federation/enhanced`와 함께 사용하며, 빌드 도구 없이 런타임 기능만 사용해야 하는 경우에는 별도로 설치할 수 있습니다.

- [npm](https://npmjs.com/package/@module-federation/runtime)
- [소스 코드](https://github.com/module-federation/core/tree/main/packages/runtime)
- [문서](/guide/runtime/index.html)

## @module-federation/rspack

![](https://img.shields.io/npm/v/@module-federation/rspack?style=flat-square&colorA=564341&colorB=EDED91)

Module Federation용 Rspack 빌드 플러그인입니다. 일반적으로 `@module-federation/enhanced`와 함께 사용하며, 런타임 API 없이 독립적으로 사용할 수 없습니다.

- [npm](https://npmjs.com/package/@module-federation/rspack)
- [소스 코드](https://github.com/module-federation/core/tree/main/packages/rspack)
- [문서](/integrations/bundler/rspack.html)

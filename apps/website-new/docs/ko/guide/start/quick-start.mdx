# 빠른 시작 가이드

이 가이드는 Module Federation을 처음 사용하는 과정을 단계별로 안내합니다. 두 개의 독립적인 Single Page Application(SPA)을 만들고, Module Federation을 사용해 한 애플리케이션의 컴포넌트를 다른 애플리케이션에서 사용하는 예제를 구성합니다.

본문에서 낯선 용어가 나오면 [용어 정리](/guide/start/glossary.html)를 함께 참고하세요.

## 요구 사항

Module Federation 빌드 플러그인을 사용하려면 Node.js 20 이상이 필요합니다.

```bash
node -v
```

기존 프로젝트에 Module Federation을 추가하려는 경우에는 [통합 문서](/integrations/index.html)에서 사용하는 프레임워크나 번들러에 맞는 패키지를 먼저 확인하세요.

## 새 프로젝트 만들기

Module Federation은 프로젝트 생성을 위한 `create-module-federation` 도구를 제공합니다. 전역으로 설치할 필요 없이 `npx`로 바로 실행할 수 있습니다.

다음 명령어로 Module Federation 프로젝트를 생성합니다.

<PackageManagerTabs
  command={{
    npm: 'npm create module-federation@latest',
    yarn: 'yarn create module-federation',
    pnpm: 'pnpm create module-federation@latest',
  }}
/>

이후 터미널에 표시되는 질문에 답하면 됩니다. 생성 과정에서 프로젝트 유형, 역할(provider/consumer), 템플릿 등을 선택할 수 있습니다.

### 템플릿

`create-module-federation`은 다음 템플릿을 제공합니다.

| Template                 | 설명                                                        |
| ------------------------ | ----------------------------------------------------------- |
| provider-modern          | [Modern.js](https://modernjs.dev/)를 사용하는 provider      |
| provider-rsbuild         | [Rsbuild](https://rsbuild.dev/)를 사용하는 provider         |
| provider-rslib           | [Rslib](https://lib.rsbuild.dev/)을 사용하는 provider       |
| provider-rslib-storybook | Storybook 기능이 활성화된 [Rslib](https://lib.rsbuild.dev/) provider |
| consumer-modern          | [Modern.js](https://modernjs.dev/)를 사용하는 consumer      |
| consumer-rsbuild         | [Rsbuild](https://rsbuild.dev/)를 사용하는 consumer         |

### 빠르게 생성하기

[create-module-federation](https://www.npmjs.com/package/create-module-federation)은 몇 가지 CLI 옵션을 제공합니다. 옵션을 지정하면 대화형 선택 과정을 건너뛰고 프로젝트를 한 번에 만들 수 있습니다.

예를 들어 `my-project` 디렉터리에 `provider`라는 이름의 Modern.js provider 프로젝트를 만들려면 다음과 같이 실행합니다.

```bash
npx create-module-federation --dir my-project --template provider-modern --name provider

# 축약 옵션 사용
npx create-module-federation -d my-project -t provider-modern -n provider
```

`create-module-federation`에서 사용할 수 있는 CLI 옵션은 다음과 같습니다.

```text
Usage: create-module-federation [options]

Options:

  -h, --help       display help for command
  -d, --dir        create project in specified directory
  -t, --template   specify the template to use
  -n, --name       specify the mf name
  -r, --role       specify the mf role type: provider or consumer
  --override       override files in target directory

Templates:

  provider-modern, provider-rsbuild, provider-rslib, provider-rslib-storybook, consumer-modern, consumer-rsbuild
```

### Provider 만들기

`create-module-federation` 명령을 실행한 뒤 필요한 프레임워크와 프로젝트 유형을 선택하고, 역할을 provider로 선택하면 provider 프로젝트가 생성됩니다.

아래는 Rsbuild provider 프로젝트를 만드는 예시입니다.

```bash
➜  ~  ✗ npm create module-federation@latest

> npx
> create-module-federation

◆  Create Module Federation Project
│
◇  Please input Module Federation name:
│  mf_provider
│
◇  Please select the type of project you want to create:
│  Application
│
◇  Select template
│  Rsbuild
│
◇  Please select the role of project you want to create:
│  Provider
│
◇  Next steps ─────╮
│                  │
│  cd mf_provider  │
│  npm install     │
│  npm run dev     │
│                  │
├──────────────────╯
│
└  Done.
```

### Consumer 만들기

마찬가지로 `create-module-federation` 명령을 실행한 뒤 역할을 consumer로 선택하면 consumer 프로젝트가 생성됩니다.

아래는 Rsbuild consumer 프로젝트를 만드는 예시입니다.

```bash
➜  ~  ✗ npm create module-federation@latest

> npx
> create-module-federation

◆  Create Module Federation Project
│
◇  Please input Module Federation name:
│  mf_consumer
│
◇  Please select the type of project you want to create:
│  Application
│
◇  Select template
│  Rsbuild
│
◇  Please select the role of project you want to create:
```

#### Provider 교체하기

기본으로 생성되는 consumer 프로젝트는 이미 배포된 provider를 사용하도록 설정되어 있습니다. 다른 provider를 사용하려면 `module-federation.config.ts`의 `remotes` 설정을 수정하세요.

```diff title="module-federation.config.ts"
import { createModuleFederationConfig } from '@module-federation/rsbuild-plugin';

export default createModuleFederationConfig({
  name: 'mf_consumer',
  remotes: {
-   'provider': 'rslib_provider@https://unpkg.com/module-federation-rslib-provider@latest/dist/mf/mf-manifest.json',
+   'provider': 'rslib_provider@http://localhost:3000/mf-manifest.json',
  },
  shared: {
    react: { singleton: true },
    'react-dom': { singleton: true },
  },
});

```

## 기존 프로젝트에 통합하기

기존 프로젝트에 Module Federation을 통합하려면 [통합 문서](/integrations/index.html)부터 확인하세요. Rsbuild, Rspack, Webpack, Modern.js, Next.js, Vite 등 프로젝트 유형별로 어떤 패키지를 설치해야 하는지 설명합니다.

## 요약

이 과정을 통해 provider에서 컴포넌트를 노출하고, consumer에서 해당 컴포넌트를 사용하는 기본 흐름을 구성했습니다. 또한 Module Federation 플러그인의 `remotes`, `exposes`, `shared` 설정이 어떤 역할을 하는지 간단히 살펴봤습니다.

기존 프로젝트에 Module Federation을 추가하려면 [통합 문서](/integrations/index.html)에서 프로젝트에 맞는 경로를 선택하세요.

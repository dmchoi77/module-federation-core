# 애플리케이션 내보내기

이 문서에서는 `createBridgeComponent`를 사용해 React 애플리케이션을 remote에서 불러올 수 있는 모듈로 내보내는 방법을 설명합니다.

## 설치

import { PackageManagerTabs } from '@theme';

<PackageManagerTabs
  command={{
    npm: 'npm install @module-federation/bridge-react@latest',
    yarn: 'yarn add @module-federation/bridge-react@latest',
    pnpm: 'pnpm add @module-federation/bridge-react@latest',
  }}
/>

## 기본 사용법

### 단계 1: 내보내기 entry 만들기

React 애플리케이션을 내보내려면 전용 export 파일을 만들고 `createBridgeComponent`로 애플리케이션을 remote 모듈로 감싸야 합니다.

애플리케이션 entry가 `App.tsx`라고 가정하면, 새 파일 `export-app.tsx`를 만듭니다.

```tsx
// ./src/export-app.tsx
import App from './App';
import { createBridgeComponent } from '@module-federation/bridge-react';

// createBridgeComponent로 App을 remote module로 감싸서 내보냅니다
export default createBridgeComponent({
  rootComponent: App
});
```

### 단계 2: `exposes`에 export 파일 등록하기

다음으로, 만든 export 파일을 다른 애플리케이션에서 사용할 수 있도록 빌드 도구의 Module Federation 설정에 expose합니다.

:::tip 빌드 도구 지원
다음 예시는 Rsbuild 설정을 사용합니다. 사용하는 빌드 도구에 맞게 조정하세요.
- **Rsbuild**: `@module-federation/rsbuild-plugin`
- **Rspack**: `@module-federation/enhanced/rspack`
- **Webpack**: `@module-federation/enhanced/webpack`
- **Vite**: `@module-federation/vite`

:::

```ts
// rsbuild.config.ts
import { pluginModuleFederation } from '@module-federation/rsbuild-plugin';

export default {
  plugins: [
    pluginModuleFederation({
      name: 'remote1',
      exposes: {
        './export-app': './src/export-app.tsx', // 애플리케이션 타입 remote module 내보내기
      },
    }),
  ],
};
```

## Bridge Router 설정

React Bridge는 현재 path에 맞춰 basename을 동적으로 주입하고 라우트 컨텍스트를 전달하는 라우팅 조정 기능을 제공합니다.

:::info 라우터 프레임워크 지원
- Bridge Router는 현재 React Router v5, v6, v7의 라우팅 프록시 기능을 지원합니다.

- `@tanstack/react-router` 같은 다른 라우팅 프레임워크는 지원하지 않습니다. React Router가 아닌 프레임워크를 사용하는 애플리케이션에서는 `enableBridgeRouter`를 명시적으로 비활성화하고 라우팅 로직을 직접 처리해야 합니다.

:::

### Bridge Router 켜기

```ts
// rsbuild.config.ts
import { pluginModuleFederation } from '@module-federation/rsbuild-plugin';

export default {
  plugins: [
    pluginModuleFederation({
      name: 'remote1',
      exposes: {
        './export-app': './src/export-app.tsx',
      },
      bridge: {
        // Bridge Router의 라우팅 기능을 켭니다. 기본값은 true입니다.
        enableBridgeRouter: true,
      }
    }),
  ],
};
```

### 설정 설명

- **`enableBridgeRouter: true`** (기본값) - basename과 라우팅 조정을 자동으로 처리하며 React Router v5, v6, v7을 지원합니다.
- **`enableBridgeRouter: false`** - Bridge의 기본 라우팅 프록시 기능을 비활성화합니다. 라우팅 통합은 사용자가 직접 처리해야 합니다.

:::warning 중요
Bridge Router를 사용할 때는 `react-router-dom`을 shared dependencies로 설정하지 마세요. shared dependencies로 설정하면 라우팅 기능에 문제가 생길 수 있습니다.
:::

## createBridgeComponent API 참고

:::warning 중요
`@module-federation/bridge-react/v18`와 `/v19`는 `react-dom/client`에서 `createRoot`를 import합니다.

`"react-dom"`만 shared dependencies로 설정하면 `react-dom/client`는 공유되지 않아 React 버전 불일치 에러가 발생할 수 있습니다. 반드시 trailing slash 접두사 형식을 사용하세요.

```ts
shared: {
  'react-dom/': {
    singleton: true,
  },
}
```
:::

### 함수 시그니처

```tsx
function createBridgeComponent<T = any>(
  bridgeInfo: Omit<ProviderFnParams<T>, 'createRoot'>
): () => {
  render(info: RenderParams): Promise<void>;
  destroy(info: DestroyParams): void;
}
```

### ProviderFnParams\<T\>

Bridge 컴포넌트 설정 매개변수입니다.

```tsx
interface ProviderFnParams<T> {
  // 루트 컴포넌트
  rootComponent: React.ComponentType<T>;

  // 직접 지정하는 render 함수(선택)
  render?: (App: React.ReactElement, id?: HTMLElement | string) => RootType | Promise<RootType>;

  // 직접 지정하는 createRoot 함수(선택, React 18 이상)
  createRoot?: (container: Element | DocumentFragment, options?: CreateRootOptions) => Root;

  // 기본 createRoot 옵션(React 18 이상)
  defaultRootOptions?: CreateRootOptions;
}
```

### RenderParams

렌더링 시 전달되는 매개변수 인터페이스입니다.

```tsx
interface RenderParams {
  moduleName?: string;
  basename?: string;
  memoryRoute?: {
    entryPath: string;
    initialState?: Record<string, unknown>;
  };
  dom: HTMLElement;                    // 렌더링 대상 DOM element
  rootOptions?: CreateRootOptions;     // React 18+ createRoot option
  [key: string]: unknown;             // 기타 사용자 정의 속성
}
```

### DestroyParams

해제 시 전달되는 매개변수 인터페이스입니다.

```tsx
interface DestroyParams {
  moduleName: string;
  dom: HTMLElement;
}
```

### CreateRootOptions

React 18 이상에서 사용할 수 있는 createRoot 옵션입니다.

```tsx
interface CreateRootOptions {
  identifierPrefix?: string;                                    // 식별자 prefix
  onRecoverableError?: (error: unknown) => void;              // 복구 가능한 에러 처리
  transitionCallbacks?: unknown;                               // 전환 콜백
}
```

### 고급 사용 예제

#### 렌더링 로직 직접 지정하기

```tsx
// ./src/export-app.tsx
import App from './App';
import { createBridgeComponent } from '@module-federation/bridge-react';
import { createRoot } from 'react-dom/client';

export default createBridgeComponent({
  rootComponent: App,

  // 직접 지정하는 render 함수
  render: (App, container) => {
    const root = createRoot(container as HTMLElement, {
      identifierPrefix: 'my-app-'
    });
    root.render(App);
    return root;
  },

  // 기본 createRoot 옵션
  defaultRootOptions: {
    identifierPrefix: 'remote-app-',
    onRecoverableError: (error) => {
      console.error('Remote app recoverable error:', error);
    }
  }
});
```

#### 여러 export 지원하기

```tsx
// ./src/export-app.tsx
import App from './App';
import Dashboard from './Dashboard';
import { createBridgeComponent } from '@module-federation/bridge-react';

// 기본 애플리케이션 내보내기
export default createBridgeComponent({
  rootComponent: App
});

// dashboard 컴포넌트 내보내기
export const dashboard = createBridgeComponent({
  rootComponent: Dashboard
});
```

이에 대응하는 Module Federation 설정은 다음과 같습니다.

```ts
// rsbuild.config.ts
export default {
  plugins: [
    pluginModuleFederation({
      name: 'remote1',
      exposes: {
        './export-app': './src/export-app.tsx',     // 기본 애플리케이션
        './dashboard': './src/export-app.tsx',      // Dashboard
      },
    }),
  ],
};
```

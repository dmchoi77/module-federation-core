# 플러그인 시스템

{props.brandName || props.name || 'Module Federation'}은 가벼운 런타임 플러그인 시스템을 제공합니다. 런타임의 여러 기능도 이 플러그인 시스템을 기반으로 구현되어 있으며, 사용자가 필요한 동작을 직접 확장할 수도 있습니다.

개발자가 작성한 플러그인은 <code>{props.brandName || props.name || 'Module Federation'}</code>의 기본 동작을 바꾸거나 다음과 같은 기능을 추가할 수 있습니다.

- 컨텍스트 정보 조회
- 라이프사이클 훅 등록
- {props.brandName || props.name || 'Module Federation'} 설정 수정
- ...

## 플러그인 개발

플러그인은 보통 `() => ModuleFederationRuntimePlugin` 형태의 함수로 제공합니다.

### 플러그인 예제

```typescript title="custom-runtime-plugin.ts"
import type { ModuleFederationRuntimePlugin } from '@module-federation/enhanced/runtime';

const runtimePlugin: () => ModuleFederationRuntimePlugin = function () {
  return {
    name: 'my-runtime-plugin',
    beforeInit(args) {
      console.log('beforeInit: ', args);
      return args;
    },
    beforeRequest(args) {
      console.log('beforeRequest: ', args);
      return args;
    },
    afterResolve(args) {
      console.log('afterResolve', args);
      return args;
    },
    onLoad(args) {
      console.log('onLoad: ', args);
      return args;
    },
    async loadShare(args) {
      console.log('loadShare:', args);
    },
    async beforeLoadShare(args) {
      console.log('beforeloadShare:', args);
      return args;
    },
  };
};
export default runtimePlugin;
```

플러그인은 아래 두 방식 중 하나로 등록할 수 있습니다.

- 빌드 시점에 등록

```typescript title="rspack.config.ts"
const path = require('path');
module.exports = {
  plugins: [
    new ModuleFederationPlugin({
      // ...
      runtimePlugins: [path.resolve(__dirname, './custom-runtime-plugin.ts')],
    }),
  ],
};
```

- 런타임에 등록

```typescript
import { registerPlugins } from '@module-federation/enhanced/runtime'
import runtimePlugin from 'custom-runtime-plugin.ts';

registerPlugins([runtimePlugin()]);
```

### 플러그인 구조

함수 기반 플러그인은 **옵션 객체를 받고** **플러그인 인스턴스를 반환**할 수 있습니다. 내부 상태가 필요하다면 클로저로 관리하면 됩니다.

각 부분의 역할은 다음과 같습니다.

- `name`: 플러그인을 식별하는 이름입니다.
- `fn`: 여러 런타임 훅을 정의합니다.

### 이름 규칙

플러그인 이름은 다음 규칙을 따르는 것을 권장합니다.

- 플러그인 함수는 `xxx-plugin` 형식의 이름으로 내보냅니다.
- 플러그인 객체의 `name`도 `xxx-plugin` 형식을 사용합니다.

예시는 다음과 같습니다.

```typescript
import type { ModuleFederationRuntimePlugin } from '@module-federation/enhanced/runtime';
const pluginFooBar = (): ModuleFederationRuntimePlugin => ({
  name: 'xxx-plugin',
  //...
});

export default pluginFooBar;
```

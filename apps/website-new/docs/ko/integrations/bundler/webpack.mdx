# Webpack

- {props.brandName || props.name || 'Module Federation'} 로딩 규격에 맞는 모듈을 빌드할 수 있습니다.
- alias를 사용해 {props.brandName || props.name || 'Module Federation'} 규격의 모듈을 소비할 수 있습니다.
- 모듈의 shared dependencies를 설정할 수 있습니다. 이미 host 환경에 같은 의존성이 있다면 다시 로드하지 않습니다.
- remote 타입이 있는 모듈은 해당 remote 모듈의 타입을 자동으로 다운로드해 사용합니다.
- remote 모듈을 소비할 때 hot reload를 사용할 수 있습니다.

다음 명령으로 플러그인을 설치합니다.

<InstallKit
  pkgName={props.enhancedPackage || props.pkgName}
/>

### {props.configName || 'module-federation.config.js'} 만들기

다음 내용으로 {props.configName || 'module-federation.config.js'} 파일을 만듭니다.

import CreateConfig from '@docs/_snippets/webpack/create-config';

{props.createConfig || <CreateConfig />}

### 플러그인 등록

`Webpack`에서는 `webpack.config.js` 설정 파일의 `plugins` 항목에 플러그인을 추가합니다.

import RegisterPlugin from '@docs/_snippets/webpack/register-plugin';

{props.registerPlugin || <RegisterPlugin />}

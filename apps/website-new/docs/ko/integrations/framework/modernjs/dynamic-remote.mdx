# Provider 동적 로드


Modern.js는 데이터 관리를 돕기 위해 [Data Loader](https://modernjs.dev/ko/guides/basic-features/data/data-fetch.html#data-loader-recommended)를 제공합니다. `Data Loader`는 서버 측에서만 실행되며 클라이언트에서는 반복 실행되지 않습니다.

이 장에서는 `Data Loader`로 producer 정보를 가져오고 이를 동적으로 로드하는 방법을 소개합니다.

## Provider 생성

동적 로드를 위한 새 provider를 만듭니다.

### 1. 설정 파일 생성

프로젝트 루트 디렉터리에 `module-federation.config.ts` 파일을 만들고 다음 내용을 작성합니다.

```ts title='module-federation.config.ts'
import { createModuleFederationConfig } from '@module-federation/modern-js-v3';

export default createModuleFederationConfig({
  name: 'dynamic_provider',
  filename: 'remoteEntry.js',
  exposes: {
    './Image': './src/components/Image.tsx',
  },
  shared: {
    react: { singleton: true },
    'react-dom': { singleton: true },
  },
});
```

### 2. 플러그인 적용

`modern.config.ts`에서 `@module-federation/modern-js-v3`를 적용합니다.

```ts title='modern.config.ts'
import { appTools, defineConfig } from '@modern-js/app-tools';
import { moduleFederationPlugin } from '@module-federation/modern-js-v3';

// https://modernjs.dev/ko/configure/app/usage
export default defineConfig({

  server: {
    ssr: {
      mode: 'stream',
    },
    port: 3008,
  },
  plugins: [appTools(), moduleFederationPlugin()],
});
```

### 3. 노출할 컴포넌트 생성

`src/components/Image.tsx` 파일을 만들고 다음 내용을 작성합니다.

```tsx title='Image.tsx'
import React from 'react';
import styles from './Image.module.css';

export default (): JSX.Element => (
  <div
    id="remote-components"
    style={{
      backgroundColor: '#c0e91e',
      color: 'lightgrey',
      padding: '1rem',
    }}
  >
    <h2>
      <strong>dynamic remote</strong>&nbsp;image
    </h2>
    <button
      id="dynamic-remote-components-button"
      style={{ marginBottom: '1rem' }}
      onClick={() => alert('[remote-components] Client side Javascript works!')}
    >
      Click me to test i'm interactive!
    </button>
    <img
      id="dynamic-remote-components-image"
      src="https://module-federation.io/module-federation-logo.svg"
      style={{ width: '100px' }}
      alt="serge"
    />
    <button className={styles['button']}>Button from dynamic remote</button>
  </div>
);
```

이어서 해당 style 파일을 다음과 같이 만듭니다.

```css title='Image.module.css'
.button {
  background: red;
}
```

## Loader 생성

해당 라우팅 파일과 같은 이름의 `.data` 파일을 만듭니다. 루트 디렉터리의 `src/routes/page.tsx`를 예로 들면 `src/routes/page.data.ts`를 생성합니다.

```ts title='page.data.ts'
import { LoaderFunctionArgs } from '@modern-js/runtime/router';

export type DataLoaderRes = {
  providerList: Array<{
    name: string;
    entry: string;
    id: string;
  }>;
};

const fetchProviderList = async () => {
  const res = await new Promise(resolve => {
    setTimeout(() => {
      resolve([
        {
          name: 'dynamic_provider',
          entry: 'http://localhost:3008/mf-manifest.json',
          id: 'dynamic_provider/Image',
        },
      ]);
    }, 1000);
  });

  return res as DataLoaderRes['providerList'];
};

export const loader = async ({
  request,
}: LoaderFunctionArgs): Promise<DataLoaderRes> => {
  console.log('request params', request);
  const providerList = await fetchProviderList();
  return {
    providerList,
  };
};
```

## 동적 Provider 로드

loader data를 사용해 해당 producer를 동적으로 로드합니다.

```tsx
import { loadRemote, registerRemotes, getInstance } from '@module-federation/modern-js-v3/runtime';
import { lazyLoadComponentPlugin } from '@module-federation/modern-js-v3/data-fetch';
// data loader 타입을 가져오기 위해 import type 사용
import type { DataLoaderRes } from './page.data';
import { useLoaderData } from '@modern-js/runtime/router';

import './index.css';

const instance = getInstance();
instance.registerPlugins([lazyLoadComponentPlugin()]);

const RemoteSSRComponent = instance.createLazyComponent({
  loader: () => import('remote/Image'),
  loading: 'loading...',
  export: 'default',
  fallback: ({ error }) => {
    if (error instanceof Error && error.message.includes('not exist')) {
      return <div>fallback - not existed id</div>;
    }
    return <div>fallback</div>;
  },
});

const Index = () => {
  // data loader 응답 가져오기
  const dataLoader = useLoaderData() as DataLoaderRes;
  // 로드하기 전에 dynamic remote 등록
  registerRemotes(dataLoader.providerList);

  const DynamicRemoteSSRComponents = dataLoader.providerList.map(item => {
    const { id } = item;
    const Com = instance.createLazyComponent({
      loader: () => loadRemote(id),
      loading: 'loading...',
      fallback: ({ error }) => {
        if (error instanceof Error && error.message.includes('not exist')) {
          return <div>fallback - not existed id</div>;
        }
        return <div>fallback</div>;
      },
    });
    return <Com />
  })
  return (
    <div className="container-box">
      <RemoteSSRComponent />
      {DynamicRemoteSSRComponents}
    </div>
  );
}

export default Index;
```

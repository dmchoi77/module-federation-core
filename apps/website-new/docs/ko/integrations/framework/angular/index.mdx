# Angular 통합 개요

Angular 앱에 Module Federation을 통합할 때는 프로젝트의 빌드 설정에 맞는 가이드를 선택하세요.

| 프로젝트 유형 | 다음 문서 |
| --- | --- |
| Angular CLI 프로젝트 | [Angular CLI 설정](/integrations/framework/angular/angular-cli.html) |
| Nx 워크스페이스 | [Angular에서 Nx CLI 사용하기](/integrations/framework/angular/using-nx-for-angular.html) |
| 전체 마이크로 프론트엔드 예제 | [Angular MFE](/integrations/framework/angular/angular-mfe.html) |
| SSR 시나리오 | [Angular SSR](/integrations/framework/angular/mf-ssr-angular.html) |
| Service Worker 시나리오 | [Module Federation과 Service Worker](/integrations/framework/angular/service-workers-mf.html) |

Angular 통합은 보통 Angular CLI, 사용자 정의 Webpack 빌더, Nx 중 하나에 의존합니다. 가이드를 선택하기 전에 현재 빌드 설정과 SSR 필요 여부를 확인하세요.

공통 Module Federation 설정 개념만 필요하다면 [설정](/configure/index.html)에서 `name`, `remotes`, `exposes`, `shared`를 확인하세요.

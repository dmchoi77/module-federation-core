# React 실습

React 앱은 React 전용 Module Federation 플러그인 하나로 고정되지 않습니다. 먼저 프로젝트에서 사용하는 bundler에 맞는 통합 방식을 선택한 뒤, 필요한 React 시나리오 가이드를 이어서 보세요.

| 프로젝트 유형 | 다음 문서 |
| --- | --- |
| Rsbuild | [Rsbuild](/integrations/build-tool/rsbuild.html) |
| Rslib | [Rslib](/integrations/build-tool/rslib.html) |
| Rspack | [Rspack](/integrations/bundler/rspack.html) |
| Webpack | [Webpack](/integrations/bundler/webpack.html) |
| Vite | [Vite](/integrations/build-tool/vite.html) |
| Runtime remote loading | [Runtime 설치](/guide/runtime/index.html#installation) |

remote React 컴포넌트를 로드해야 한다면 [Bridge](/guide/bridge/overview.html)를 이어서 보세요. remote 컴포넌트에 data fetching, data cache, prefetch가 필요하다면 [Data Management](/guide/data/data-fetch.html)를 참고하세요.
